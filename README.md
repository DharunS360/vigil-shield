# 🛡️ VigilShield — SOC Alert Triage Platform

Production-grade SIEM dashboard with real-time alert ingestion, custom detection rules, MITRE ATT&CK mapping, and IOC enrichment.

## ✨ Features

### Backend (FastAPI)
- 🔥 REST API for alerts, incidents, MITRE mapping
- 📡 WebSocket for real-time updates
- 🎯 Alert correlation engine
- 🧠 Threat intelligence service
- 💾 SQLite database with SQLAlchemy
- 🔐 JWT authentication

### Frontend (React + TypeScript)
- 📊 SOC Dashboard with live metrics
- 🚨 Alert management (list, details, triage)
- 📋 Incident tracking
- 🎯 MITRE ATT&CK matrix visualization
- 📈 Charts and statistics (Recharts)
- 🌗 Dark/Light theme
- 📱 Responsive design
